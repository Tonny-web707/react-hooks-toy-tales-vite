# Toy Tales – React CRUD Application

Toy Tales is a React application that helps Andy organize his toy collection.

Users can view toys, add new toys, like their favorite toys, and donate toys they no longer need.

## Features

- View all toys fetched from a JSON Server API.
- Add new toys with a name and image URL.
- Like toys and increase their like counts.
- Donate toys by deleting them from the collection.
- Automatically update the displayed collection after changes.

## Technologies Used

- React
- JavaScript
- React Hooks (useState and useEffect)
- Vite
- JSON Server
- HTML and CSS
- Vitest
- React Testing Library
